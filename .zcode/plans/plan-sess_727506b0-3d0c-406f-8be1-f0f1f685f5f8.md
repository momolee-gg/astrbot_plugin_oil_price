# 修复调价提醒：预告应展示「下次调价预测」而非上次调价

## Context（问题与根因）

**Bug**：调价提醒（预告）文案把**上一次调价**的涨跌额当成即将到来的调价展示：

```
⛽ 江苏：明晚 24 时调价窗口开启！要加油的今晚抓紧
92号汽油：8.85 元/升（↑涨 0.27）   ← 这是 10-30 已生效的上轮调价（+345元/吨）
```

本轮（11-12 24时）实际**预计下调**，文案却显示"涨 0.27"并建议"今晚抓紧加油"——数据错误 + 建议反向。根因：`build_remind_text`（modules/reporting.py:104）直接复用数据源的 `change` 字段（=上轮调价涨跌，已在现行价中生效），且 `adjust_countdown_text` 的赶油建议写死为涨价场景。

**用户要求**：预告要给**下次调整的预警**（方向+幅度）。

**预测方案（已验证）**：ShowAPI 138-49 无预测字段；东财旧预测报表已停更（止于2024）。已实测可用免费源=东方财富两个公开 JSON 接口（无需 key）：
- WTI 日线：`push2his.eastmoney.com/api/qt/stock/kline/get?secid=102.CL00Y`（实时到 2026-11-12 ✓）
- 官方调价历史（生效日+汽柴油Δ元/吨）：`datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPTA_WEB_YJ_BD`（DIM_DATE=生效日，与插件现有 next_change_time 口径一致，已用时间线互证）

**回测结论**（60 次真实调价）：按发改委机制取 WTI「10 个交易日移动均价 环比上周期」变化率，`元/吨 ≈ 变化率% × 42`（经验系数）→ **方向准确率 98%（49/50），幅度中位误差 64 元/吨 ≈ 0.05 元/升**；本轮实测预测 -382元/吨（新闻口径 -280）。足以做带「约/以发改委公告为准」限定的预警，绝不可伪装成精确值。

## 改动

### 1. 新增 `modules/forecast.py`（预测模块）
- `fetch_raw()`：urllib 同步拉上述两个接口（沿用 datasource.py 的 urllib 模式，调用方 `asyncio.to_thread` 包裹）；超时 10s。
- `estimate()`：`MA_now`=最近 10 个交易日均价；`MA_prev`=截止上次生效日前一交易日的 10 日均价；`rate=(MA_now/MA_prev-1)*100`；`per_ton=rate*42`（常数含注释：60 周期回测中位数）；`|per_ton|<50 → 搁浅`。
- 输出结构：`{"dir": "rise|drop|flat", "per_ton": float, "delta": {"92": 0.29, "95": 0.30, "98": 0.30, "0": 0.33, "89": ...}, "rate": float}`；每升系数：汽油 0.00078、柴油 0.00086（由本轮实际 345→0.27、335→0.29 反推，注释说明）。
- 数据不足/接口失败/日期错位 → 返回 None（含 freshness 校验：MA_prev 终点距上次生效日 ≤20 交易日）。
- `get_today_forecast(today)`：按天缓存（模块级 dict），避免多省份集/命令重复拉取。

### 2. `modules/reporting.py`（核心文案修复）
- `adjust_countdown_text(next_time, direction=None)`：days==1/0 的建议按方向分型——涨价→保留"要加油的今晚抓紧"；降价→"预计降价，等明晚降价后再加更划算"；搁浅/未知→中性"调价窗口开启"（**不再默认涨价建议**）。
- `build_remind_text(rows, fuels=None, forecast=None)`：
  - **有 forecast**：价格行 `92号汽油：现价 8.85 元/升（预计 ↓降约 0.29）`（多省带省份前缀，沿用现状）；notice 区加一行 `⚡ 预计每吨下调约 380 元，以发改委公告为准`（只写元/吨——避免含"元/升"被 genimage 误分类进数据区）；倒计时行带方向建议。
  - **无 forecast（兜底）**：价格行只显 `现价 X.XX 元/升`，**不再带任何涨跌标注**（核心修复：宁可少说，不可错说）；建议中性。
  - 签名向后兼容（现有测试子串断言不受影响）。

### 3. `modules/genimage.py`（海报支持预测胶囊）
- `_ROW_CHANGE_RE`（genimage.py:23）放行 `预计 ↓降约 0.29` 形式：`[↑↓]` 前允许 `预计\s*` 前缀 → 海报数据行照常渲染红/绿胶囊；提示区"上调/下调"红绿放规则已存在（genimage.py:168-169）无需改。

### 4. `main.py`（接线）
- `_advance_remind`（main.py:337）：生成提醒文案前 `forecast = await asyncio.to_thread(get_today_forecast, today)`，失败 log warning + 传 None（兜底文案）。
- `/调价窗口` 指令（main.py:1050）：追加一行预测摘要（如"预计下调约 380 元/吨 ≈ 92号 0.29 元/升，以公告为准"）；失败不影响原输出。

### 5. `modules/charts.py`（同类小修，单省原生卡片）
- render_report_card 倒计时行（charts.py:1345）"明晚 24 时调价，今晚加油还按现价！"为涨价场景写死——改为接收可选 direction 参数（查询/推送路径同 day 缓存取 forecast），无预测时中性化"明晚 24 时调价窗口开启"。

### 6. 测试与文档
- `test/test_oil_plugin.py` 新增：forecast 解析与测算（mock urlopen：正常/搁浅/数据不足/日期错位）、build_remind_text 有/无 forecast 文案断言（含多省前缀、不得出现上次涨跌标注）、genimage 正则匹配预测胶囊、/调价窗口输出。
- 全量回归：`python test/run_local.py`（现有 108 用例须全过）。
