⚙️ 推送设置
每日定时推送与月度走势图的省份、时间与目标
🏭 推送省份（可多选）
每日推送与 /今日油价 缺省时使用的省份；多省推送合成为一张长图，每省一个独立板块
⏰ 推送时间
单省推送为「文字版 + 图片版」两条消息；多省仅推送图片版
🔁 推送频率
每日 = 每天到点推送；每周 = 仅在每周推送日推送；关闭 = 不发常规推送，调价提醒与月度图不受影响（旧配置「有变动时」已并入调价提醒）
🔔 调价提醒
任意推送频率下生效：距下次调价窗口剩余 ≤ N 天时每日一条提醒（AI 图片，失败回退文字）+ 调价落地后推送最新油价；0 = 关闭
🧭 推送省份自适应
开启后推送与缺省查询按会话内最近查询的省份自动选择（私聊按本人、群聊按成员聚合，取最近 3 个），不足时回退已配置省份
🧠 查询省份记忆管理
省份自适应所记忆的各会话查询记录（每目标滚动保留最近 50 条）。可修改某条的省份集、删除单条或清空某目标记忆，清空后回退已配置省份

🖼️ 图片消息开关
开启后推送与 /今日油价 发送 AI 生成的图片（每天随机换一种风格，不连续重复）；关闭后只发文字。生图失败自动回退文字
♻️ 当日生图缓存
同一天相同内容的海报只真实生成一次，重复查询/推送直接复用已有图片（秒回、省生图费用）；关闭后每次都真实生成
📅 每月推送油价走势图
每月 1 日按推送时间向推送目标发送上一月的每日油价折线图
👤 私聊推送目标（绑定每日查询上限）
每行一个 QQ 号；限额留空 = 使用全局默认。该目标内用户的每日查询次数按此限额计量
👥 群聊推送目标（绑定每日查询上限）
每行一个群号；限额留空 = 使用全局默认。该群内用户的每日查询次数按此限额计量
🔢 每人每日查询上限
/油价 等指令的每人每日次数上限，设为 0 表示不限制

卡片展示与 看看油价 / 我要加油 缺省的油号，可多选；指令未指定时使用第一个
