# 03 · 项目开发文档

适用版本：v1.0.0（AstrBot 4.29.1 / Python 3.12）

## 1. 总体架构

```text
main.py                 插件入口：7 条指令 + 3 个 Web API + 定时推送编排（频率调度/变动检测/提前提醒）
config.py               Prefs：配置唯一读写/校验层
modules/
  constants.py          零依赖常量层（省份/油种/UMO 前缀/颜色/调色板）
  datasource.py         ShowAPI 数据源客户端（urllib，异常归一 ShowApiError）
  storage.py            history.json（按省按日）+ user_quota.json（配额）
  reporting.py          文字文案（单省报告 / 多省速览 / 调价倒计时 / 上涨下调持平三场景提示）
  genimage.py           AI 生图（文字消息→逐行引用提示词→bot 已配置 provider 生图端点；5 风格轮换）
  charts.py             PIL 渲染（单油种卡 / 小票 / 折线图，折线图支持明暗双主题）
views/config/index.html WebUI 设置页（今日油价 / 油价统计 双 tab，自包含单文件）
.astrbot-plugin/i18n/   视图标题等 i18n 元数据
```

依赖方向：`main.py → config.py → modules/constants.py`；`modules/*` 之间互不引用，
只允许依赖 `constants` 与标准库 / Pillow。

## 2. 目录与运行数据

| 路径 | 内容 |
|------|------|
| 插件目录 | 源码（进 Git） |
| `data/plugin_data/astrbot_plugin_oil_price/history.json` | 按省按日查询历史 |
| `data/plugin_data/astrbot_plugin_oil_price/user_quota.json` | 用户每日配额计数 |
| `data/plugin_data/astrbot_plugin_oil_price/tmp/` | 推送/指令生成的临时 PNG |
| `data/config/astrbot_plugin_oil_price_config.json` | AstrBot 持久化的插件配置 |

运行数据一律不进仓库。

## 3. 配置结构（_conf_schema.json）

`basic`：

| 键 | 类型 | 说明 |
|----|------|------|
| provinces | list[str] | 推送省份多选（31 省码表） |
| push_hour / push_minute | int | 每日推送时间 |
| monthly_push | bool | 每月走势推送开关 |
| notify_private / notify_group | list[str] | 推送目标 UMO 列表 |
| target_limits | dict | {UMO: 单独每日上限}，未设置用全局默认 |
| user_daily_limit | int | 全局默认每日上限（0=不限） |
| default_fuels | list[str] | 默认油号多选 |

`api`：

| 键 | 类型 | 说明 |
|----|------|------|
| app_key | string | ShowAPI appKey（secret 性质，不入 Git） |

注意：`object` 类型在 schema 解析时必须带 `items`；需要任意动态键时使用 `dict`。

## 4. 关键流程

### 4.1 查询

```text
指令 → appKey 门控 → 配额扣减（UMO|sender 维度）
     → 当日缓存命中？ 读缓存 : fetch_province（线程池）
     → store_prices 落盘 → 渲染/文案 → 回复
```

- 上游失败统一抛 `ShowApiError`，指令层转友好提示
- 文件名 `price_{prov}_{fuel}`、`report_{prov}_{date}` 等按维度命名

### 4.2 定时推送

```text
_daily_loop（20s 轮询，配置热读取）
  到达 push_time：
    每日：单省=文字版+图片版两条；多省=一张拼接长图
    每月1日：上一月折线图（开关）
  _pushed_date/_pushed_month 内存去重
```

推送目标为空或全部查询失败时跳过；单目标失败不影响其他目标。

### 4.3 配额

- 键：`{unified_msg_origin}|{sender_id}`
- 上限解析：`target_limits[umo]` 优先，否则 `user_daily_limit`；0=不限
- 跨天自动重置（按日期比对）

## 5. Web API 与 WebUI

| 端点（bridge 视角） | 方法 | 说明 |
|---------------------|------|------|
| `config/get` | GET | 全量配置 + 选项码值（省份/油号表由后端下发） |
| `config/save` | POST | 全字段校验（正反例见测试案例文档 TC-C 系列），错误返回 400 |
| `stats/render` | POST | 折线图 base64 PNG + 汇总表；appKey 未配置返回 400 |

前端运行在沙箱 iframe，经 `window.AstrBotPluginView` bridge 通信；
已知约束：无 `allow-popups`（外链回退复制）、对主文档 opaque origin、
bridge 注入是对 `</body>` 的朴素字符串替换（页面脚本不得含 `</body>` 字面量）。

## 6. 事件 API 约定（踩坑记录）

- 图片回复必须用 `event.chain_result([...])`；**没有** `event.chain()`
- appKey 门控提示用 `yield event.plain_result(...)`；`event.send()` 不接受
  `MessageEventResult`
- 测试 mock 只允许模拟上述真实方法，防止“测试绿但线上炸”

## 7. 已知限制（v1.0.0 如实记录）

- 历史/配额 JSON 为整文件覆盖写，未原子化；极端情况可能截断
- 临时 PNG 文件名按维度确定性生成，高并发下可能互相覆盖
- 指令省份参数未强制码表校验（WebUI 已校验）
- appKey 在 config/get 中完整返回（有鉴权保护，但建议后续掩码化）
- 文字报告“近期走势”依赖 trend_series 数据契约，需 ≥2 天历史
- `/油价设置`、`/油价推送测试` 暂未限制管理员

## 8. 升级与迁移

- schema 变更由 AstrBot 启动时自动合并：新增补默认、删除清字段
- `dict` 类型保留任意动态键（如 target_limits 的 UMO 键）
- 旧字段 `province`/`default_fuel` 已废弃，不做自动迁移（生产已手动迁移）

## 9. 故障处理速查

| 症状 | 排查 |
|------|------|
| 全部指令回复“未配置 appKey” | 设置页填写 appKey 并保存 |
| 出图失败收到文字版 | 查看 `/tmp` 与插件日志中 charts 异常 |
| 推送未到达 | 检查 UMO 是否有效、目标机器人是否在线 |
| 统计页“暂无历史数据” | 历史按天积累，需 ≥2 个查询日 |
