# 02 · 项目需求 v1.0（修订第一版）

状态：已确认（2026-10-23）。本文档为 v1.0 需求基线，后续变更需追加修订记录。

## 1. 用户角色

| 角色 | 说明 | 主要使用方式 |
|------|------|--------------|
| 群成员 | 群聊内普通用户 | 指令查询油价、加油计算 |
| 私聊用户 | 与机器人单聊的用户 | 同上（受目标限额约束） |
| 管理员 | 机器人维护者 | WebUI 设置页管理全部配置；指令设置常用偏好 |

## 2. 功能需求

### FR-1 指令查询

- FR-1.1 `/油价 [省份]`：文字版油价；缺省播报全部已配置省份（紧凑格式）
- FR-1.2 `/今日油价 [省份]`：出图版；缺省时多省合一长图，单省为独立卡片
- FR-1.3 `/看看油价 [省份] [油号]`：单油种大字卡片；缺省省份/油号取已配置第一项
- FR-1.4 `/我要加油 <升数> [省份] [油号]`：生成电子小票（单价、总价、较上次调价差价）
- FR-1.5 出图失败时自动回退文字版，保证可用性
- FR-1.6 查询结果带「较上次调价」涨跌（涨红跌绿）

### FR-2 定时推送

- FR-2.1 每日在配置时间（时:分）向全部推送目标推送当日油价
- FR-2.2 单省：文字版 + 图片版两条消息；多省：仅一张拼接长图
- FR-2.3 当日去重：同一天不重复推送；失败不写去重标志（允许下轮重试）
- FR-2.4 每月 1 日推送上一月每日油价折线图（开关可关）

### FR-3 油价统计

- FR-3.1 WebUI 按省份（多选）、油号（多选）、范围（7/30/90/180 天）生成折线图
- FR-3.2 附每条线汇总：起始价、最新价、涨跌、最低/最高/均价、样本天数

### FR-4 配置管理（WebUI）

- FR-4.1 推送省份多选（全国 31 省固定码表）
- FR-4.2 每日推送时间（时:分）
- FR-4.3 私聊/群聊推送目标行编辑器：目标 ID + 单独每日限额（留空用全局默认）
- FR-4.4 全局默认每日上限（0=不限）
- FR-4.5 默认油号多选
- FR-4.6 appKey 管理：不回显完整值，保存留空表示保持原值
- FR-4.7 保存即时生效；appKey 就绪后推送定时器自动补启

### FR-5 指令快捷设置

- FR-5.1 `/油价设置 <省份> <油号>`：等同设置页修改省份（单选）与油号
- FR-5.2 无参数时展示当前配置

### FR-6 容错与门控

- FR-6.1 appKey 未配置：所有查询/推送/统计入口统一拦截并提示
- FR-6.2 接口失败：指令回复原因；推送全部省份失败时不推送
- FR-6.3 配额超限：回复剩余次数/上限提示

## 3. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | 上游请求不阻塞事件循环（线程池/异步） |
| NFR-2 | 每省每天至多 1 次上游请求（当日缓存） |
| NFR-3 | 历史/配额 JSON 原子写入，损坏不静默覆盖 |
| NFR-4 | 配额按「目标 UMO + 用户」独立计量，跨天重置 |
| NFR-5 | appKey 不入日志、不入 Git、前端不回显完整值 |
| NFR-6 | 热重载必须取消旧后台任务，避免重复推送 |
| NFR-7 | 指令省份参数统一走码表校验，非法值不进入 API 与文件名 |
| NFR-8 | 兼容 AstrBot >= 4.29.1、Python >= 3.12 |

## 4. 数据与安全

- appKey、推送目标、查询历史、配额均属敏感/隐私数据，只存 AstrBot 数据目录
- 仓库内不出现任何真实 appKey、QQ 号、群号、服务器地址（示例一律用占位符）
- 测试使用隔离目录与 mock 数据，不得读写生产配置

## 5. 验收标准

1. 全部自动化测试通过（确定性套件零失败、零错误、零无意跳过）
2. 真实 QQ 环境：7 条指令可用，出图在客户端清晰可读
3. 每日/每月推送到达配置目标，格式符合 FR-2.2
4. WebUI 设置页保存后重启，配置不丢失
5. 未配置 appKey 的全新安装：指令被拦截并给出引导提示
