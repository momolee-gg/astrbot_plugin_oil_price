# 油价插件（astrbot_plugin_oil_price v1.0.0）测试案例文档

> 生成日期：2026-10-23
> 被测对象：AstrBot 插件 astrbot_plugin_oil_price（ShowAPI 数据源）
> 自动化脚本：插件目录 `tests/test_oil_plugin.py`（unittest，容器内运行）
> 数据隔离策略：自动化测试全部使用 `/tmp/oil_plugin_test/` 隔离目录与 mock 数据，**不读写真实配置/历史/配额文件**；脚本运行前后对真实配置文件做 md5 校验，并在 `/tmp/oil_backup/` 留存备份。

## 一、功能清单

### A. QQ 指令（7 条）
| # | 指令 | 功能 | 缺省行为 |
|---|------|------|----------|
| A1 | `/油价 [省份]` | 文字版快速查询 | 不带省份 → 播报全部已选省份（紧凑多行） |
| A2 | `/今日油价 [省份]` | 出图版播报 | 不带省份 → 多省拼接长图；单省/带省份 → 单省卡 |
| A3 | `/看看油价 [省份] [油号]` | 单油种大字卡片 | 缺省省份=已选第一个；缺省油号=已选第一个 |
| A4 | `/我要加油 <升数> [省份] [油号]` | 加油电子小票 | 同上缺省规则 |
| A5 | `/油价设置 <省份> <油号>` | 快捷设置省份/油号 | 无参数 → 显示当前配置 |
| A6 | `/调价窗口` | 下次调价倒计时 | 取已选第一个省份 |
| A7 | `/油价推送测试` | 立即向推送目标执行一次每日推送 | — |

### B. 自动推送
| # | 功能 | 说明 |
|---|------|------|
| B1 | 每日定时推送 | 到达配置时间触发（20s 轮询，当日去重） |
| B2 | 单省推送格式 | 文字版 + 图片版 **两条**消息 |
| B3 | 多省推送格式 | 仅一张拼接长图（每省独立板块） |
| B4 | 月度走势推送 | 每月 1 日按推送时间发上一月折线图（开关控制） |
| B5 | 推送目标 | 群聊 + 私聊 UMO 列表，逐个投递、失败不影响其他 |

### C. WebUI 设置页（侧边栏「今日油价」）
| # | 功能 | 说明 |
|---|------|------|
| C1 | 顶部 tab | 油价统计 / 系统配置 两个页签切换 |
| C2 | 推送设置 | 省份多选、推送时间、月度推送开关、私聊/群聊目标与目标单独限额、全局默认上限、默认油号多选 |
| C3 | 接口配置 | 数据源（文本）、官方地址（超链接，沙箱拦截时回退复制）、appKey（含配置状态徽章） |
| C4 | 保存 | 位于系统配置页内部（降一级），保存即时生效并自动补启推送定时器 |
| C5 | 油价统计 | 省份/油号多选 + 范围（7/30/90/180 天）→ 折线图 + 汇总表 |

### D. Web API（注册在 `/astrbot_plugin_oil_price/*`）
| # | 端点 | 方法 | 说明 |
|---|------|------|------|
| D1 | `config/get` | GET | 返回全量配置 + 选项码值 + 结构化目标（ID/单独限额） |
| D2 | `config/save` | POST | 全字段校验后写入并持久化 |
| D3 | `stats/render` | POST | 按省/油号/天数渲染折线图（base64 PNG + 汇总） |

### E. 数据层
| # | 功能 | 说明 |
|---|------|------|
| E1 | 当日缓存 | 每省每天仅调一次 API，之后读缓存 |
| E2 | 查询历史 | 按省按日落盘（折线图/月报/趋势数据源） |
| E3 | 目标绑定配额 | 配额按「目标 UMO + 用户」独立计数；目标单独限额优先，未设置目标回退全局默认（0=不限） |
| E4 | 配置持久化 | 保存即写盘；appKey 保存后自动补启推送定时器 |

### F. 渲染
| # | 图型 | 说明 |
|---|------|------|
| F1 | 单省卡 | 油种行式，大字价格+涨红跌绿+调价倒计时 |
| F2 | 多省长图 | 每省独立板块（省名+油种横列），一张图 |
| F3 | 单油种大字卡 | 看看油价 |
| F4 | 加油小票 | 我要加油 |
| F5 | 折线图 | 统计页/月报，多线多色+图例，2x 抗锯齿 |
| F6 | 油号过滤 | 以上卡片/文案只渲染已配置油号 |

### G. 门控与容错
| # | 场景 | 行为 |
|---|------|------|
| G1 | appKey 未配置 | 推送定时器不启动；全部查询指令回复提示 |
| G2 | 网络/接口失败 | 指令回复失败原因；推送出图失败回退文字版 |
| G3 | 配额超限 | 指令回复上限提示 |
| G4 | 非法输入 | 升数非数字、配置字段非法等均友好提示 |
| G5 | 目标规范化 | 纯数字 QQ/群号自动补 UMO 前缀；完整 UMO 原样保留 |
| G6 | 目标绑定限额 | 私聊/群聊每个目标可单独设每日查询上限；留空使用全局默认 |

## 三、执行方式

```bash
# 容器内直接运行；执行全量测试并自动生成 Markdown 测试报告：
docker exec astrbot python3 \
  /AstrBot/data/plugins/astrbot_plugin_oil_price/tests/test_oil_plugin.py
```

- 报告路径：插件 `docs/reports/测试报告-v1.0.0.md`。
- 真实 API 冒烟（可选，消耗 1 次付费配额）：`OIL_LIVE=1` 环境变量开启。
- 测试数据目录：`/tmp/oil_plugin_test/`（跑完必须删除）。
- 真实配置备份：`/tmp/oil_backup_v1.0.0/`（运行前创建，测试后 md5 校验一致；如不一致立即恢复）。
- **定版准入规则**：新增功能已补用例 + 全量自动化测试 0 失败 + 生成测试报告，三项缺一不可。
