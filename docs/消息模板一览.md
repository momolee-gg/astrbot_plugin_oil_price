# 二、调价前预测提醒（独立推送类型）

## 2.1 单省 · 有预测方向

| 场景要素 | 说明 |
|---|---|
| 触发时机 | 距下次调价窗口剩余 **1~N 天**内的每天（N＝`change_remind_days` 配置，0＝关闭） |
| 频率条件 | **所有目标行不看常规频率**——daily/weekly/off 行都收（这是独立推送类型） |
| 口径 | 推算口径（东财测算），绝不用上次涨跌额冒充下次调整 |
| 数据条件 | 预测方向明确（涨/降）→ 价格行挂「预计 ↓降约」标注 |
| 与常规播报的关系 | **完全独立并存**：当天已发常规播报后本条照发（oil_1011 去抑制） |
| 窗口日 | 剩余 0 天**不发**——当天由第三类「官方公告提醒」接管 |
| 接收者·载体 | 该目标行内：umo 行＝文字一条 + AI 海报一条；webhook 行＝仅文字版 |
| 去重 | 每行每省集每天至多一条（行级状态键去重） |

# 四、新价落地补发

| 场景要素 | 说明 |
|---|---|
| 触发时机 | **生效日当日**（数据源 `before_change_time == 今天`），该目标行配置时刻到点 |
| 频率条件 | **无开关总发**：daily/weekly/off 行都收；weekly 行非指定星期也收 |

# 附 A｜图片失败回退规则（适用于所有含海报的消息）

- 图片开关关闭 / bot 未配置生图端点 → 直接只发文字版（推送与查询一致）
- 出图过程失败 → 文字版 + `⚠️ 海报生成失败，已回退文字版`（查询路径另附配置提示语）
- AI 海报以**已生成的文字模板**为唯一提示词来源（图文同源），当日统一风格、按日期轮换不连续重复
