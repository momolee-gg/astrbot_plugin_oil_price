# 消息模板一览（oil_1011 口径）

> 基于分支 `dev_oil_1011` 实际代码生成（2026-11-18）。
> 样例态势：江苏 92号 8.34 元/升（11-12 已降 0.51 生效），下次调价生效日 11-27（窗口日 11-26 24时）。
> 日期与倒计时随实际日期动态变化，以下为当日快照。

## 口径判定（所有播报类消息共用）

按顺序判定，命中即停：

| 顺序 | 条件 | 口径 | 价格行标注 |
|---|---|---|---|
| 1 | 今天=窗口日（生效日前一天）且官方公告已发布 | official | `（公告 ↓降约 0.51）` |
| 2 | 今天=窗口日且公告未发布 | forecast | `（预测 ↓降约 0.09）` |
| 3 | 上次调价 ≤7 天 | last | `（↓已降 0.51）` |
| 4 | 上次调价 >7 天，预测可取得 | forecast | `（预测 ↓降约 0.09）` |
| 5 | 上次调价 >7 天，预测不可得 | neutral | 无标注（尾部挂上次调价摘要） |

## A1｜单省推送 · last 口径 · 降价日

| 场景要素 | 说明 |
|---|---|
| 触发时机 | 目标行配置时刻到点（全局默认或行内覆盖的 HH:MM） |
| 频率条件 | 该行 frequency=daily，或 weekly 且今天是行内指定星期 |
| 口径判定 | 上次调价 ≤7 天（非窗口日） |
| 数据条件 | 展示油号中任一 `change < 0`（多油号同涨跌并存时**上涨优先**） |
| 接收者·载体 | 该目标行：umo 行＝**文字一条 + AI 海报一条**；webhook 行＝仅文字 |
| 去重 | 当天该行该省集只发一次（槽守卫）；落地补发与此模板相同（见文末互斥说明） |

```
🎉🎉 油价下调提醒 🎉🎉
⛽ 江苏油价（11-18）
92号汽油：8.34 元/升（↓已降 0.51）
95号汽油：8.87 元/升（↓已降 0.54）
98号汽油：10.94 元/升（↓已降 0.54）
0号柴油：8.01 元/升（↓已降 0.54）

⚡ 92号汽油、95号汽油、98号汽油、0号柴油下调！本轮降幅已生效，今天起加油更省钱！下次调价窗口（11月26日 24时）前价格保持不变

📅 距下次调价窗口（11月26日 24时）还有 8 天
```

⚡ 行随窗口距离变化：剩 1 天→「明晚 24 时迎来下一个调价窗口」；当天→「今晚 24 时就是下一个调价窗口」。

## A4｜单省播报 · forecast 口径（>7 天 / 窗口日公告前）

| 场景要素 | 说明 |
|---|---|
| 触发时机 | 目标行配置时刻到点（频率同 A1），**或窗口日当天常规到点且公告未发布** |
| 口径判定 | 顺序 2 或 4（见顶部口径表） |
| 数据条件 | 预测方向明确（rise/drop）→ 价格行挂「预测」标注；搁浅/未知 → 无标注 |
| 接收者·载体 | 同 A1（推送）；`/油价`、`/今日油价` 查询同样走此文案（中性路径见 A7 说明） |
| 附注 | 预测器需窗口后 ≥5 个交易日数据；不足时走 A6 |

```
⛽ 江苏油价（11-18）
92号汽油：8.34 元/升（预测 ↓降约 0.09）

```

预计搁浅时 ⚡ 行变：`⚡ 预计本轮调价幅度不足 50 元/吨，大概率搁浅维持现价（以发改委公告为准）`

## A5｜单省播报 · official 口径（窗口日公告后）

| 场景要素 | 说明 |
|---|---|

| 口径判定 | 顺序 1 |
| 数据条件 | forecast 官方探针返回 per_ton（每吨官方幅度，每升为按系数折算） |
| 接收者·载体 | 同 A1 |
| 附注 | 与 C1（官方公告提醒）同日并存——见文末候选优化点 2 |

```

## B1｜调价前预测提醒 · 单省

| 场景要素 | 说明 |
|---|---|
| 触发时机 | 距下次调价窗口剩余 **1~N 天**（`change_remind_days`，0=关闭）内，每天一次 |
| 与常规关系 | **完全独立并存**：当天已发常规播报仍照发（oil_1011 去抑制） |
| 口径 | 推算口径（东财测算），绝不用上次涨跌冒充下次调整 |
| 数据条件 | 预测方向明确→价格行挂「预计」标注；方向未知→只报现价（B3）；搁浅→B4 |
| 窗口日 | **不发**（剩余 0 天）——当天由官方公告推送接管 |
| 接收者·载体 | 同 A1；行级去重（每行每省集每天一条） |

```
🚨🚨 调价提醒 🚨🚨
⛽ 江苏：距下次调价窗口（11月26日 24时）还有 2 天
92号汽油：现价 8.34 元/升（预计 ↓降约 0.09）
95号汽油：现价 8.87 元/升（预计 ↓降约 0.10）
98号汽油：现价 10.94 元/升（预计 ↓降约 0.10）
0号柴油：现价 8.01 元/升（预计 ↓降约 0.10）
⚡ 预计每吨下调约 120 元，以发改委公告为准
```

剩 1 天倒计时行变：`⛽ 江苏：明晚 24 时调价窗口开启！预计降价，等明晚降价后再加更划算`（涨价则「要加油的今晚抓紧」）。

## C1｜窗口日官方公告提醒 · 单省

| 场景要素 | 说明 |
|---|---|
| 触发时机 | **仅窗口日当天**，16:30-23:50 每 10 分钟轮询，官方公告数据发布后立即发送 |
| 硬性条件 | 官方 per_ton 数据存在才发；**公告未发布绝不发估算值冒充** |
| 倒计时口径 | 当天剩余 0 天 →「就是今晚 24 时」；措辞「已公告」 |
| 接收者·载体 | 全部目标行（不看其常规频率/时刻）；每行每省集当天至多一条 |
| 与 A5 关系 | 窗口日当天 daily 行会先收 A5（播报）后收 C1（提醒），两条并存——见候选优化点 2 |

```

95号汽油：现价 8.87 元/升（↓降约 0.54）
98号汽油：现价 10.94 元/升（↓降约 0.54）

## C2｜窗口日官方公告提醒 · 多省

同 C1 触发/硬性条件；每省一组「⛽ 省份：倒计时 + 省份前缀价格行」，尾部同一条官方 ⚡ 摘要；umo 行仅海报、webhook 行收本文字。

## 落地补发（=A1-A3 同款模板，触发不同）

| 场景要素 | 说明 |
|---|---|
| 触发时机 | **生效日当日**（数据源 `before_change_time == 今天`），目标行配置时刻到点 |
| 开关 | 无开关总发（off 行也收） |
| 互斥 | 当天该行常规播报已发则跳过（两者同为最新油价播报，不重复） |
| 口径 | 必为 last（生效日当天距上次调价 0 天） |

## 手动指令与回执（不进推送链路）

| 入口 | 行为 | 回执文案 |
|---|---|---|
| `/油价调整`（管理员） | 向全部目标广播一轮**当日口径**的 A 区模板（不写去重状态、可重复执行） | `✅ 常规播报已推送至 N 个目标（按当日涨跌额口径渲染）`；全失败→`未能推送：全部省份查询失败` |
| `/油价推送测试`（管理员） | 仅指令会话自检，**不广播** | `✅ 油价插件测试消息：通道连通正常。`＋`推送省份：… · 默认油号 …号`＋`推送时间 HH:MM · 推送目标 N 个` |
| WebUI 目标行「测试」按钮 | 对该行目标发连通测试（无需保存，不查行情） | `✅ 油价插件测试消息：通道连通正常。当前推送省份：…` |
| `/油价订阅`（管理员） | 当前会话加入推送目标 | `✅ 已订阅：本群聊将跟随默认调度接收油价推送（可在设置页目标行单独调整频率/时刻）` |
| `/油价退订`（管理员） | 当前会话移出推送目标 | `✅ 已退订：本会话不再接收油价推送` |

## 图片失败回退规则（适用于所有含海报的模板）

- 图片开关关闭 / 无生图端点 → 直接只发文字版
- 出图失败 → 文字版 + `⚠️ 海报生成失败，已回退文字版`（查询路径提示语略不同）

## 候选优化点（待定，未实施）

1. **A1/A2 ⚡ 行罗列全部油号**——可简化为按代表油号概括（如「本轮油价已下调，92号 ↓0.51」）
