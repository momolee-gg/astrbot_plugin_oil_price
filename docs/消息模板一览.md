# 消息模板一览（oil_1011 口径）

> 基于分支 `dev_oil_1011` 实际代码生成（2026-11-18）。
> 样例态势：江苏 92号 8.34 元/升（11-12 已降 0.51 生效），下次调价生效日 11-27（窗口日 11-26 24时）。
> 日期与倒计时随实际日期动态变化，以下为当日快照。

## 一、推送场景总览

| # | 消息类型 | 触发时机 | 涨跌口径 | 载体与接收者 |
|---|---|---|---|---|
| A1-A3 | 常规播报（单省） | daily/weekly 行到点；**落地补发同款** | last（≤7 天） | 单省＝**文字 + 海报图**各一条 |
| A4/A6 | 常规播报（单省） | 同上 | forecast / neutral | 同上 |
| A5 | 常规播报（单省） | 窗口日到点 | official（公告后） | 同上 |
| A7 | 用户查询 | `/油价 江苏`、`/今日油价` 海报 | 按当日口径 | 文字 / 海报图（中性无警报标题） |
| A8/A9 | 常规播报（多省） | daily/weekly 行到点 | 按当日口径 | 多省＝**仅海报图**（webhook 行改收速览文字） |
| B1-B4 | 调价前预测提醒 | 窗口前剩余 1~N 天（`change_remind_days`），**独立于常规频率、与常规并存** | 预测 | 单省＝文字+海报图；多省＝仅海报图 |
| C1/C2 | 窗口日官方公告提醒 | 窗口日 16:30-23:50 轮询，**公告数据发布后**才发 | 官方 | 当天每目标行至多一条 |
| — | 落地补发 | 生效日当日（`before_change_time == 今天`），无开关总发、与当日常规互斥 | last | 复用 A1-A3 模板 |
| — | `/油价调整` | 手动（管理员） | 按当日口径 | 向全部目标广播一轮 A 区模板 |
| — | `/油价推送测试` | 手动（管理员） | — | 仅指令会话回执，不广播 |

**口径判定优先级**：窗口日（公告前→forecast / 公告后→official）＞ 上次调价 ≤7 天（last）＞ >7 天（forecast；预测不可得→neutral）。

## 三、候选优化点（待定，未实施）

1. **A1/A2 ⚡ 行罗列全部油号**——可简化为按代表油号概括（如「本轮油价已下调，92号 ↓0.51」）
2. **窗口日双重播报**——daily 行窗口日会先收 A5（播报含官方口径），公告发布后又收 C1（官方公告提醒），内容重叠度高；可考虑合并或跳过其一
3. **C1 价格行标注「↓降约 0.51」与 A5「公告 ↓降约 0.51」不一致**——提醒模板自带标题语境，是否统一加「公告」前缀待定
4. **多省速览 `8.30` 显示为 `8.3`**（`:g` 去尾零）——可改 `:.2f` 统一两位小数
5. **B 区多省提醒每省重复倒计时行**——各省窗口相同，可只保留首省
