# 01 · 项目简介

## 背景

群机器人（AstrBot）需要一个开箱即用的油价能力：每天自动播报所在省份的油价变化，
群成员随时可以查询油价、计算加油花费，并在调价窗口前收到提醒。

本项目以 AstrBot 插件形式实现该能力，数据来源为万维 ShowAPI 的全国油价接口
（138-49 单省行情），已在线上 AstrBot 4.29.1 + Python 3.12 环境稳定运行。

## 定位

- 面向 QQ 群聊 / 私聊场景的油价查询与播报插件
- 单机部署、单实例运行，配置与数据全部落在 AstrBot 数据目录
- 私有维护项目，不含开源许可证

## 核心功能一览

| 模块 | 能力 |
|------|------|
| 指令查询 | 文字版 / 出图版 / 单油种大字卡 / 加油小票 / 调价倒计时 |
| AI 生图海报 | 每日图片由当天文字消息交给 bot 已配置模型平台生成（图文同源），上涨/下调/持平三场景自动适配，5 种风格随机轮换 |
| 定时推送 | 推送频率可配（每日 / 每周 / 有变动时），单省双消息、多省合一图，图片开关可关、失败回退文字 |
| 调价提醒 | 距下次调价窗口 N 天（可配）时额外发送文字提醒 |
| 月度推送 | 每月 1 日推送上一月每日油价折线图（可开关） |
| 油价统计 | WebUI 内按省份/油号/范围生成折线图与汇总（跟随页面明暗主题） |
| 目标限额 | 每个推送目标可绑定单独的每日查询上限 |
| 设置页 | 今日油价（系统配置）+ 油价统计 双 tab，保存即时生效 |

## 数据源

- 万维 ShowAPI · 全国油价接口（138-49）
- 认证方式：appKey（用户在 ShowAPI 控制台申请）
- 免费档按次计费：插件通过「当日缓存 + 配额上限」控制调用量

## 支持环境

| 项 | 要求 |
|----|------|
| AstrBot | >= 4.29.1（实测 4.29.1） |
| Python | >= 3.12 |
| 平台 | aiocqhttp（QQ）实测可用 |
| 字体 | 容器内 Noto Sans CJK（中文出图） |
