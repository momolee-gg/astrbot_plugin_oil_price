# astrbot_plugin_oil_price · 今日油价

AstrBot 插件：全国油价查询、卡片出图、定时推送与走势统计（数据源：万维 ShowAPI）。

> **私有项目（Private / Internal）**：本仓库未设置开源许可证，未经授权请勿分发。
> 油价数据来自第三方接口，仅供参考，请以当地加油站实际价格为准。

## 功能

- **11 条指令**：`/油价`（文字版）、`/今日油价`（出图版）、`/看看油价`（单油种大字卡）、
  `/我要加油`（加油小票）、`/油价设置`、`/调价窗口`、`/油价调整`、`/油价推送测试`、
  `/油价订阅`、`/油价退订`、`/飞书群列表`
- **AI 生图海报**：每日图片由当天文字消息直接交给 bot 已配置模型平台的生图端点生成（图文同源），
  上涨/下调/持平三种场景自动匹配标题与建议文案，5 种风格随机轮换、不连续重复
- **每日定时推送**：调度 = 全局默认（每日/每周/关闭 + 时刻）+ 目标行可单独覆盖频率/时刻；
  单省 = 文字版 + 图片版两条消息，多省 = 一张图片版；图片开关关闭或生图端点不可用时自动回退纯文字
- **通用推送目标（不区分平台）**：QQ 号/群号、任意平台完整 UMO、飞书群 webhook（地址##加签密钥）、
  飞书 ou_/oc_/手机号/邮箱，一个列表混配、格式自动识别派发；设置页可从「记录的会话」点选填入
  （按机器人分组），目标群内发 `/油价订阅` 一键加入
- **调价提醒**：独立于常规推送频率（0=关闭）——窗口前剩余 1~N 天每日发送一条
  **预计**涨跌预告（第三方行情测算，以公告为准）；窗口日仅在公告数据发布后
  发送**官方**每吨幅度与约每升折算值，未公告不以估算冒充；新价落地后价格
  快照有变动时再推送最新油价。图片失败回退文字；旧「有变动时」配置自动迁移
- **推送省份自适应**（可开关）：记住会话内最近的查询省份，推送与裸指令缺省省份
  自动跟随——私聊按本人、群聊按成员聚合，不足时回退已配置省份
- **每月走势推送**：每月 1 日向推送目标发送上一月每日油价折线图（可开关）
- **油价统计页**：按省份/油号/时间范围生成折线图与汇总表（WebUI 内嵌，跟随页面明暗主题）
- **目标绑定限额**：每个私聊/群聊推送目标可单独设置每日查询上限，未设置用全局默认
- **WebUI 设置页**：省份/油号多选、推送时间与频率、提前提醒、图片开关与生图模型、目标与限额、
  appKey 管理（今日油价 + 油价统计 双 tab）

## 安装

将本仓库克隆到 AstrBot 插件目录：

```bash
cd /AstrBot/data/plugins
git clone https://github.com/momolee-gg/astrbot_plugin_oil_price.git
```

或在 WebUI「插件」页通过仓库地址安装。安装后：

1. 在侧边栏「今日油价 → 系统配置 → 接口配置」填写 ShowAPI appKey（[控制台获取](https://www.showapi.com/)）
2. 勾选推送省份、配置推送时间与目标
3. 保存即生效（appKey 就绪后推送定时器自动启动）

## 指令

| 指令 | 说明 |
|------|------|
| `/油价 [省份]` | 文字版；不带省份时播报全部已选省份 |
| `/今日油价 [省份]` | 图片版（AI 生图，随机风格）；不带省份时多省合一图 |
| `/看看油价 [省份] [油号]` | 单油种大字卡片 |
| `/我要加油 <升数> [省份] [油号]` | 加油结算单 |
| `/油价设置 <省份> <油号>` | 快捷记住省份/油号 |
| `/调价窗口` | 下次调价窗口倒计时 |
| `/油价调整` | 立即向全部推送目标发送一条调价提醒（官方口径优先，其次推算口径；不影响自动推送节奏） |
| `/油价推送测试` | 向全部推送目标立即执行一次每日播报推送 |
| `/油价订阅` | 把当前会话加入推送目标（管理员；群/私自动归类，调度跟随默认） |
| `/油价退订` | 把当前会话移出推送目标（管理员） |
| `/飞书群列表` | 列出飞书应用机器人已加入的群（chat_id），供配置群推送目标 |

## 推送目标与调度

配置全部在 WebUI「今日油价 → 系统配置 → 推送设置」，**不区分平台**：

**目标串格式（自动识别派发）**

| 目标串 | 归类 | 能力 |
|------|------|------|
| QQ 号 / 群号（纯数字） | QQ（按列表补 `default:` 前缀） | 文字 + 海报图片 |
| 完整 UMO（`平台:类型:ID`，任意平台） | 对应平台会话 | 取决于该平台适配器 |
| 飞书群 webhook（`https://open.feishu.cn/…##加签密钥`） | 飞书群自定义机器人 | 仅文字（官方限制不能收图/私发） |
| 飞书 `ou_` / 手机号 / 邮箱；群 `oc_` | 飞书自建应用（需在「接口配置」填凭证） | 文字 + 海报图片 |

**调度**：全局默认（频率 + 时:分 + 每周几），目标行可单独覆盖（留空跟随默认）。
主循环按「时:分」分槽批量执行；调价预警、官方公告、月度走势图送达全部目标，
去重状态按「目标行 × 省份集」隔离，互不重发漏发。

**会话选择器**：设置页「从记录会话选择」——插件运行期间收过消息的会话自动记录，
按机器人分组、可搜索，点选即添加为目标行（群/私自动归类）。也可以直接在目标群里发
`/油价订阅` 一键加入（`/油价退订` 移除）。飞书自建应用目标用 `/飞书群列表` 查 chat_id。

**飞书自建应用配置**（个人/群目标与海报图片的前提）：[飞书开放平台](https://open.feishu.cn/document/server-docs/im-v1/message/create)创建
「企业自建应用」，开通机器人能力并发布版本；「接口配置」成对填写 App ID/App Secret，
应用需开通 **im:message** 权限（手机号/邮箱定位用户还需「根据手机号或邮箱获取用户 ID」）。
